# Illustrations Directory

This directory will contain all SVG illustrations for the Domax platform.

## Structure

```
illustrations/
  workflows/        # Core workflow illustrations
  features/         # Feature-specific illustrations
  personas/         # User persona illustrations
  educational/      # Educational context illustrations
  empty-states/     # Empty state illustrations
  onboarding/      # Onboarding flow illustrations
  celebrations/    # Success and celebration elements
```

## Usage

All illustrations should:
- Be SVG format for scalability
- Use CSS variables for theming
- Be optimized for web (SVGO)
- Include proper alt text when used in components

## Color Theming

Illustrations use CSS variables:
- `var(--brand-primary-blue)` for #005ffe
- `var(--brand-teal)` for #00cd90
- `var(--brand-navy)` for #0A3059

See `ILLUSTRATION_ECOSYSTEM.md` for complete specifications.
